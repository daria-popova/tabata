# Interval Timer App

Мобильное приложение для интервальных тренировок (HIIT / Tabata).

Цель проекта:

* сделать кастомный таймер тренировок с гибкими настройками
* изучить мобильную разработку (React Native + Expo)
* реализовать приложение "для себя"

## 🧱 Технологии

* React Native
* Expo
* TypeScript
* Expo Router (навигация)
* SQLite (локальное хранение)

## ✨ Основные функции (MVP)

* создание тренировки
* редактирование интервалов
* запуск таймера
* отображение текущего этапа
* звуковые сигналы при смене этапов
* сохранение тренировок локально

## 🧠 Концепция

Тренировка состоит из последовательности этапов:

* разминка
* работа
* отдых
* повторения
* заминка

Приложение "разворачивает" тренировку в линейный список шагов и проигрывает их.

## 🚀 Запуск проекта

```bash
npm install
npx expo start
```

## 📦 Структура проекта (планируемая)

```
app/                # экраны (Expo Router)
components/         # переиспользуемые UI компоненты
features/workouts/  # логика тренировок
lib/db/             # работа с SQLite
types/              # типы и интерфейсы
```
