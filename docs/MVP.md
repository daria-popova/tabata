# MVP — Interval Timer

## 🎯 Цель

Собрать рабочее приложение таймера тренировок.

## 📱 Экраны

### 1. Список тренировок

* список сохранённых тренировок
* кнопка "создать"

### 2. Создание / редактирование

* название тренировки
* список этапов
* добавление / удаление этапов

### 3. Экран таймера

* текущий этап
* оставшееся время
* прогресс
* кнопки: старт / пауза / стоп

### 4. Настройки (минимально)

* звук вкл/выкл

## 🧭 После MVP

### Работа таймера в фоне

Цель: таймер продолжает идти, когда пользователь переключился в другое приложение
например книжку или YouTube, а звуковые сигналы по возможности проигрываются в
моменты смены этапов.

План доработки:

* вынести состояние и расчёт таймера в отдельный хук
* считать прогресс от абсолютного времени (`Date.now()`), а не полагаться только
  на `setInterval`
* обрабатывать переходы приложения между состояниями `active`, `inactive`,
  `background` через `AppState`
* сохранять активную сессию таймера в локальное хранилище
* при возврате в приложение пересчитывать текущий этап и прогресс
* включить и проверить background audio для звуковых сигналов
* протестировать поведение на реальном телефоне в development build
* если короткие звуки из фона работают ненадёжно, рассмотреть fallback через
  локальные уведомления

Важно: фоновые задачи Expo не подходят для секундного таймера, потому что ОС не
гарантирует точный запуск кода в фоне. Поэтому базовая надёжность должна
строиться на пересчёте времени от абсолютного timestamp.
