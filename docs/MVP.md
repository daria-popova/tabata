# MVP — Interval Timer

## 🎯 Цель

Собрать рабочее приложение таймера тренировок.

## 📱 Экраны

### 1. Список тренировок

* список сохранённых тренировок
* кнопка "создать"

### 2. Создание / редактирование

* название тренировки
* список этапов
* добавление / удаление этапов

### 3. Экран таймера

* текущий этап
* оставшееся время
* прогресс
* кнопки: старт / пауза / стоп

### 4. Настройки (минимально)

* звук вкл/выкл

---

## 🔧 Функциональность

* [ ] создать тренировку
* [ ] редактировать тренировку
* [ ] удалить тренировку
* [ ] запуск таймера
* [ ] переход между этапами
* [ ] звуковой сигнал
* [ ] сохранение в SQLite

## ✅ Критерий готовности

Приложение:

* позволяет создать тренировку
* сохраняет её
* корректно проигрывает от начала до конца
