# Calories Feature Plan

## 🎯 Цель

Добавить в приложение функцию оценки сожжённых калорий во время тренировки.

Фича должна:

* давать пользователю понятную и полезную оценку
* быть простой в использовании
* не требовать сложного ввода данных

---

## 📦 Объём (Scope)

В первой версии:

* расчёт калорий на основе длительности упражнений
* использование MET (метаболического эквивалента)
* поддержка базового набора упражнений
* учёт веса пользователя

Не входит:

* интеграция с пульсом / датчиками
* высокая медицинская точность
* персонализированные модели

---

## ⚠️ Особенности задачи

* расчёт **приблизительный**, не точный
* значения MET — усреднённые
* один и тот же пользователь может тратить разное количество энергии
* важно правильно подать результат (округление, ~)

---

## 🧠 Подход к расчёту

Используется модель:

* каждое упражнение имеет коэффициент MET
* калории считаются по длительности

Особенности:

* динамические упражнения → MET зависит от интенсивности
* статические упражнения → фиксированный MET

---

## 🏋️ Типы упражнений

### 1. Динамические (с интенсивностью)

* зависит от темпа выполнения
* пользователь может выбирать уровень

### 2. Статические (без интенсивности)

* фиксированная нагрузка
* интенсивность не выбирается

## 👤 Данные пользователя

Минимально:

* вес (обязательно)

Опционально (будущее):

* пол
* возраст

---

## 🧩 Логика расчёта

* каждая часть тренировки имеет длительность
* для неё определяется MET
* считается расход калорий
* значения суммируются

---

## 🖥️ Отображение пользователю

Показывать:

* калории за тренировку
* (опционально) за этап

Формат:

* округлённые значения
* с тильдой (~)

Пример:

* ~85 ккал

---

## 🎛️ UX решения

* не перегружать пользователя
* интенсивность показывать только там, где она реально есть
* можно задать значения по умолчанию

---

## 🚀 Возможные улучшения

* автоматическое определение интенсивности
* кастомные упражнения
* учёт отдыха
* интеграция с пульсом
* более точные формулы

---

## ✅ Критерии готовности

* калории считаются для всех упражнений
* расчёт работает для любой тренировки
* пользователь видит итоговое значение
* интерфейс остаётся простым и понятным
